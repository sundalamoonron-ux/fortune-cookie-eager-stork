An entry for make.fun's [Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) bounty.

The fortune:

> "The bug you cannot reproduce will reproduce itself in front of your manager."

## Run

```sh
python3 main.py
```

This writes the fortune line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
